炸弹哈基迷 · 试玩版

当前开放 1–2 层主线、两场 BOSS 战、干员招募和切换、家具平台、探索地图与专属打击特效。3–6 层仍在制作。

这是浏览器单机游戏，建议使用电脑键盘和鼠标。当前没有触屏操作、联网合作或跨设备存档；刷新页面会重新开始。

  • A / D 或方向键：移动；空格：跳跃
  • J / 鼠标左键：攻击；迷迭香在空中直接下砸
  • 其他干员空中 S + J：专属向下攻击；K / Shift：闪避或格挡
  • L / 鼠标右键：大招；E：交互；1–4：切换干员
  • B / Tab：招募面板；M：地图；N：音乐开关

每位干员的空中打法

  • 迷迭香：空中直接按 J 巨盾下砸，无需按 S。穿过家具和中间平台，在实体楼板上触发大范围冲击。
  • 年：空中 S + J 坠刃重斩。同样砸到实体楼板，范围较窄，伤害更高并带眩晕。
  • W：空中 S + J 向下投弹，自己保持正常移动和下落。空中再按跳可发动一次炸弹二段跳，没有下砸。
  • 可可：空中 S + J 向下斩击，命中敌人或医疗无人机可借力弹起，保留高跳与滑铲。
  • 小火：空中 S + J 向下喷火，利用反推力缓降；长按跳可消耗燃料短暂飞行，没有下砸。

下砸不会在桌面、柜顶、吊台或医疗无人机上触发落地冲击；切换干员、闪避或受击会中断下砸。
